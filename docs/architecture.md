# 架构与扩展约定

## 分层

`backend/core` 定义 Principal、ExecutionContext、ModelGateway、Retriever、MemoryStore、EventStore、ExecutionPolicy 与工具注册表，不依赖工厂业务或 Web/ORM。`backend/infra` 实现 MySQL/SQLAlchemy、模型网关、加密、检查点。`backend/services` 实现工厂应用和 LangGraph 运行时适配。

新增业务应用应组合核心协议与基础设施适配器，不复制 HTTP 层、认证或 SQL 编译器。`examples/tool_agent.py` 可独立运行。长期记忆只有协议；调度、多 Agent 和人工审批尚无专门的执行模块。首期没有可视化流程编辑器。完整实现边界见 [交付说明书](delivery-guide.md)。

## 感知与编排

主图：START → route → knowledge / data / mixed / clarify → answer → END。

路由收到当前问题、经当前权限过滤的会话上下文、获授权且被 Agent 开放的业务主题。返回完整问题、路由、主题和是否存在串行依赖。所有模型结构化输出都通过 Pydantic 校验；无效输出结束运行并记录失败，不猜测执行。

知识子图包含 retrieve → validate。数据子图运行计划生成、编译及查询。mixed 无依赖时通过 asyncio.gather 并行调用两子图；需要知识口径时先检索，证据不足则澄清，不继续查询。

运行使用 user_id:run_id 隔离检查点。会话级上下文存储在 messages，不通过共享图状态跨用户复用。检查点含状态、父检查点与 pending writes；API 启动恢复 queued/running 运行。突然断电恢复可重新执行尚未提交的节点，当前工具均只读。未来接入写操作必须增加幂等键与审批，不能直接复用只读恢复语义。

## RAG

PDF 按页提取；DOCX 提取段落及表格；MD/TXT 使用 UTF-8。每块约 700 字符，重叠 100 字符；保留页码或段落位置。扫描 PDF 无文字时导入失败并提示转换。

模型服务负责向量化，MySQL 保存 float32 向量及模型标识。FAISS 每知识库采用精确内积检索，查询和库向量归一化；关键词使用 MySQL FULLTEXT WITH PARSER ngram，两路使用 RRF 融合。SQLite 仅用作开发测试，关键词检索是简化回退，效果不能代替 MySQL 验收。

FAISS 索引为派生缓存：不可变索引文件 + 原子 manifest 切换。查询核对活跃分块集合，索引缺失或过期时用数据库向量构造临时精确索引；不会为了匹配旧索引而漏掉新资料。保留旧索引世代便于进程安全切换，可停机清理 indexes 目录后重建。

新文档版本入库期间旧版本继续服务；向量就绪后以事务切换活跃版本，索引随之更新。当前实现切换后可能短暂走数据库向量回退。改变向量模型时应重新导入全部知识，不能混用向量空间。

## 权限

默认拒绝。资源若同时配置角色和部门，两个条件必须同时满足；配置维度为空代表该维度不限制，但两者都为空不向普通用户开放。管理员仍不能访问 disabled 资源；业务查询中管理员也只查询自身部门，避免调试路径意外扩大数据权限。

文档继承知识库权限。检索只搜索授权知识库；引用下载和预览单独检查。运行记录 scope 包含用户版本、授权资源版本及活跃文档版本；变化后隐藏历史内容、停止旧运行访问并要求重新提问。该策略较保守：可见资料更新也会使旧回答重新验证，未来可细化为逐来源重算。

部门值来自平台用户记录，模型和浏览器都不能覆盖。主题必须配置 department_field；未配置不能保存启用。宿主用户 ID 只能通过持有服务凭据的宿主后端交换令牌。令牌只持有用户 ID 与权限版本，每次请求读取当前用户状态。

## 数据主题

fields 是逻辑键到 `别名.列名` 的白名单；dimensions 只能引用白名单键，metrics 仅允许 sum/avg/min/max/count；joins 只允许预配置的等值关联。模型只输出字段键与筛选值，服务端生成 SQL 并强制部门条件。

单主题单数据源；不开放子查询、任意 SQL、任意函数和跨源联邦查询。每次连接开启 READ ONLY 事务，MAX_EXECUTION_TIME 限制 SELECT，socket 超时限制连接等待。数据库账号还需由 DBA 授予审核过的表/视图 SELECT 权限。多表一对多关联可能改变指标口径，管理员应使用已确认的业务视图并在真实数据验收中核对。

## 已知验收边界

模拟模型使用确定性规则和哈希向量，只用于流程演示；不是训练模型，不用于衡量真实语言理解或问答准确率。基于合成数据的自动测试不能代替真实模型、MySQL 8.0.31、4 核 8GB 虚拟机和真实业务资料的现场验收。
