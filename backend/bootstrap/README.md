# 启动与初始化模块

## 职责

读取环境配置、校验生产参数、显式创建引导和演示数据。

## 依赖与公开边界

导入包不能执行初始化；__main__.py 是显式 CLI，设置读取不加载种子数据。

## 阅读顺序与使用说明

settings.py → seeding.py；python -m backend.bootstrap --demo --drain-jobs 仍兼容。

## 文件清单

- `__init__.py`
- `__main__.py`
- `seeding.py`
- `settings.py`

## 学习要点

通过公开协议或明确入口组合能力，避免跨层访问内部存储。阅读函数注释中的权限、异常、事务和恢复约束；新增实现必须保持这些契约。目录的存在不代表该能力具备自主决策循环。
