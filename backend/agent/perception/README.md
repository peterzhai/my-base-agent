# 感知模块

## 职责

结合上下文和可用主题生成结构化路由。

## 依赖与公开边界

依赖 PerceptionPorts 和 ContextBuilder；不读取数据库或构造模型。

## 阅读顺序与使用说明

router.py 是策略，contracts.py 是输入端口，schemas.py 是路由数据。工厂提示语仍保留在策略中，未来可按应用注入。

## 文件清单

- `__init__.py`
- `contracts.py`
- `router.py`
- `schemas.py`

## 学习要点

通过公开协议或明确入口组合能力，避免跨层访问内部存储。阅读函数注释中的权限、异常、事务和恢复约束；新增实现必须保持这些契约。目录的存在不代表该能力具备自主决策循环。
