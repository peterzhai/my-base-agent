# 执行上下文与事件协议模块

## 职责

保存单次执行身份、预算、取消信号，定义事件持久化端口。

## 依赖与公开边界

纯协议和值对象；实际运行编排在工厂应用，SQL 事件存储在 infrastructure/persistence。

## 阅读顺序与使用说明

context.py 的 check 和 events.py 的 EventStore。未提供独立的通用自主执行器。

## 文件清单

- `__init__.py`
- `context.py`
- `events.py`

## 学习要点

通过公开协议或明确入口组合能力，避免跨层访问内部存储。阅读函数注释中的权限、异常、事务和恢复约束；新增实现必须保持这些契约。目录的存在不代表该能力具备自主决策循环。
