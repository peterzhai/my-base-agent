# 响应组织模块

## 职责

校验当前证据并生成文本、引用与表格事件。

## 依赖与公开边界

依赖 ResponsePorts；不访问知识索引或数据库连接。

## 阅读顺序与使用说明

composer.py:ResponseComposer.answer。流式每段输出都检查取消和权限，避免长连接绕过撤权。

## 文件清单

- `__init__.py`
- `composer.py`
- `contracts.py`

## 学习要点

通过公开协议或明确入口组合能力，避免跨层访问内部存储。阅读函数注释中的权限、异常、事务和恢复约束；新增实现必须保持这些契约。目录的存在不代表该能力具备自主决策循环。
