## 依赖与公开边界

## 阅读顺序与使用说明

新路径请查 docs/module-map.md。此目录的存在不代表有第二份基础设施。

## 学习要点

通过公开协议或明确入口组合能力，避免跨层访问内部存储。阅读函数注释中的权限、异常、事务和恢复约束；新增实现必须保持这些契约。目录的存在不代表该能力具备自主决策循环。
