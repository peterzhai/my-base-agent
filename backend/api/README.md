# HTTP API模块

## 职责

安装认证依赖并将领域操作映射为 HTTP/SSE。

## 依赖与公开边界

外部 HTTP 路径保持不变；共享请求模式在 schemas.py，共享身份依赖在 dependencies.py。

## 阅读顺序与使用说明

每个领域目录的 routes.py 放接口；__init__.py 只公开 router 和必要的共享入口。

## 文件清单

- `__init__.py`
- `dependencies.py`
- `schemas.py`

## 学习要点

通过公开协议或明确入口组合能力，避免跨层访问内部存储。阅读函数注释中的权限、异常、事务和恢复约束；新增实现必须保持这些契约。目录的存在不代表该能力具备自主决策循环。
