# 受控数据查询模块

## 职责

生成查询计划、验证模式、编译 SQL 并只读执行。

## 依赖与公开边界

模型不得提供任意 SQL；部门条件来自服务端身份；字段与关联来自审核主题。

## 阅读顺序与使用说明

schemas.py → service.py → compiler.py → executor.py。SQL 编译与执行分离，方便分别测试注入防护和连接限制。

## 文件清单

- `__init__.py`
- `compiler.py`
- `executor.py`
- `schemas.py`
- `service.py`

## 学习要点

通过公开协议或明确入口组合能力，避免跨层访问内部存储。阅读函数注释中的权限、异常、事务和恢复约束；新增实现必须保持这些契约。目录的存在不代表该能力具备自主决策循环。
